### `argparse`

**Definition:** `argparse` is a Python library used to **read and process command-line arguments** provided by the user when running a program.

Example:

```bash
python app.py data.log --top 10
```

`argparse` reads `data.log` and `10` and makes them available to the Python program.

**Interview definition:**

> "`argparse` is a Python standard-library module used to build command-line interfaces and parse arguments passed to a Python program."

### `pytest`

**Definition:** `pytest` is a Python testing framework used to **automatically test whether your code works correctly**.

Example:

```python
def test_add():
    assert 2 + 3 == 5
```

Run:

```bash
pytest
```

**Interview definition:**

> "`pytest` is a Python testing framework that discovers and runs test functions and reports whether the expected behavior passes or fails."
